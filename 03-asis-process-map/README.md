### Key Process Gaps & Friction Points Identified:
* **Feature Discovery Problem:** The journey is entirely passive and buried 3 levels deep under Settings. 40% of customers never locate the feature.
* **Lack of Initial Guidance:** The text-only selection list provides no visual examples, leading customers to choose the wrong document type.
* **Perceived App Freezing:** When a file is uploaded, no systemic loading bar or progress indicator appears. 9% of users force-close the app thinking it crashed.
* **The Rejection Support Spike:** Automated systemic rejections only display a generic "Try again" error. Because users are given zero indication of what went wrong (e.g., blur, glare, or file size), 65% of rejected customers abandon the journey and open manual support tickets.
